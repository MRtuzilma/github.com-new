# BT Ekran (v4.3) — launcher ichida

`classes.dex` — BT Ekran v4.3 ilovasining tayyor (kompilyatsiya qilingan) kodi.
GitHub Actions APK yig'ilgandan keyin uni launcher APK'siga `classesN.dex` sifatida qo'shadi
va APK'ni qayta imzolaydi. BT Ekran komponentlari (`uz.ekranbt.*`) `AndroidManifest.xml` da e'lon qilingan.
Launcherdagi "BT" tugmasi `uz.ekranbt.MainActivity` ni ochadi.
